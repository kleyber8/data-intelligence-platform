# 📚 Portal de Documentación: Data Intelligence Platform

Bienvenido a la base de conocimiento técnico de la **Data Intelligence Platform**. 

Esta carpeta contiene la documentación modular del proyecto. En lugar de un único archivo monolítico, el conocimiento se ha dividido en manuales independientes para garantizar una lectura ágil, evitar la sobrecarga cognitiva y facilitar el mantenimiento a largo plazo.

## 💡 ¿Por dónde empezar?

*   **Si eres nuevo en el proyecto:** Lee el documento **01** para entender el propósito, y luego el **06** para levantar el entorno local y verlo funcionar.
*   **Si quieres entender el código y la infraestructura:** Ve directamente al **02** (Arquitectura) y al **03** (Estado de las fases).
*   **Si eres auditor o científico de datos:** El **05** (Calidad y Gobernanza) y el **04** (Seguridad) contienen las garantías técnicas del pipeline.

Toda decisión técnica relevante en este proyecto está registrada bajo el siguiente esquema metodológico:

> **Problema → Alternativas → Decisión → Justificación → Consecuencias → Mejoras Futuras**
